# Images Directory

This directory contains images for the Te Puo website.

## Required Images

### Homepage (index.html)

1. **dorodango-sphere-hero.jpg**
   - Location: Hero section
   - Description: A polished dorodango sphere showcasing the Japanese technique
   - Recommended size: 800x800px (1:1 aspect ratio)

2. **dorodango-process.jpg**

## Image Guidelines

- Use earth tones and natural colors that match the brand aesthetic
- Optimize images for web (compress without losing quality)
- Provide WebP format with JPEG fallback for best performance
- Ensure all images have descriptive alt text for accessibility
- Maximum file size: 500KB per image (recommended)

## Placeholder Images

Until actual images are available, the site will gracefully handle missing images:
- Alt text will be displayed
- CSS will style broken image placeholders
- Layout will remain intact

## Adding Images

1. Place image files in this directory
2. Update the `src` attribute in the HTML to match the filename
3. Ensure alt text is descriptive and meaningful
4. Test on different screen sizes to verify responsive behavior
